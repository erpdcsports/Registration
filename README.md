# DC Sports Academy — Student Admission & Portal

Official lightweight web onboarding and student management portal for **DC Sports Academy**. Designed for marketing via QR codes on posters, banners, flyers, and social media.

## ✨ Features
- **📝 Online Admission Application**: Dynamic branch, sports, and batch selection with real-time seat availability and fee plans (1-Month & 3-Month quarterly).
- **🔑 Student Login**: Direct login with Mobile Number / Student ID to view enrolled batches, timing, fee receipts, and monthly attendance count.
- **💳 Online Fees Payment**: Integrated Razorpay checkout for instant online tuition fee settlement.
- **📷 Instant QR Code Generator**: Built-in 1-click HD QR code generation and download tool for printing on academy marketing materials.
- **📲 Google Play Integration**: Direct link to download the official Android application.

## 🚀 How to Push to your new GitHub Repository:

1. Create a new repository on GitHub (e.g. `dc-sports-portal` or `dc-sports-apply`).
2. Run the following commands in this directory:

```bash
git init
git add .
git commit -m "feat: initial commit for student admission and login portal"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-new-repo>.git
git push -u origin main
```

3. Go to **Settings > Pages** in your new GitHub repository:
   - **Source**: Deploy from a branch
   - **Branch**: `main` / `/(root)`
   - Click **Save**.
4. Your portal will be live at: `https://<your-username>.github.io/<your-new-repo>/`
